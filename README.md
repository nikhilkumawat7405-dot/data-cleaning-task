# Data Cleaning & Preparation

## Dataset
Student Performance Dataset from the UCI Machine Learning Repository.

## Objective
The objective of this task is to clean and prepare the dataset for further analysis.

## Cleaning Steps Performed
- Checked the dataset for missing values.
- Checked for duplicate records.
- Checked the data types of columns.
- Reviewed categorical values for consistency.
- Removed duplicate records where found.
- Removed rows with missing values where required.
- Saved the cleaned dataset as `cleaned_student_data.csv`.

## Tools Used
- Python
- Pandas
- Google Colab

## Files
- `cleaned_student_data.csv` – Cleaned dataset
- `Untitled2 (1).ipynb` – Google Colab notebook containing the cleaning process

## Output
The final cleaned dataset is included in this repository and is ready for further analysis.
