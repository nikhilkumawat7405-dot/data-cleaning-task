
# Exploratory Data Analysis – Student Performance Dataset

## Dataset
Student Performance Dataset containing 395 records and 33 columns.

## Important Statistics
- Average Final Grade (G3): 10.42
- Highest Final Grade: 20
- Lowest Final Grade: 0
- Average Absences: 5.71

## Key Insights
1. The average final grade provides an overall view of student performance.
2. Final grades are concentrated around the middle grade range.
3. Study time shows differences in average final grades between students.
4. Students with more previous failures generally show differences in final performance.
5. Absences show variation in relation to final grades.
